# ספר הצ׳אנס של אבא — מהדורת הספר המוגדל

ספר RTL על כל שטח התצוגה. 12 שורות בכתב גדול כברירת מחדל; דפדוף בגרירה, סימוני צבע וקווים, הערות וסימניות. הסינון, הסטטיסטיקות והייבוא נמצאים בחלוניות לפי דרישה. כפתור מסך מלא משתמש ב־Fullscreen API כאשר הדפדפן מאפשר זאת.

## עדכון תוצאות

`GET /api/results?page=1` מושך את עמוד הארכיון https://hatulbul.com/chance/archive דרך השרת. האתר הוא מקור עצמאי ולא מקור רשמי. התוצאה נבדקת לפי מספר הגרלה, תאריך, שעה וארבע סדרות; לא משולב HTML מרוחק בעמוד. עמודים נוספים נקראים רק מתוך אותו מקור קבוע. לא מתקבלת כתובת URL חופשית מהמשתמש.

הספר בודק מדי שתי דקות כשהוא פתוח וגלוי, ובחזרה ללשונית, ומאפשר כפתור עדכון ידני. יש מטמון זמני של 120 שניות בזיכרון מופע השרת, ללא תלות ב־default cache שאינו מורשה בפלטפורמה. משיכה אחת משלימה עד 20 עמודים ואז מאפשרת המשך. אין תזמון כשהספר סגור; בפתיחה הבאה מתבצעת השלמה. האפשרות ״השלמת הארכיון״ מושכת עמודים זמינים במרווח של שתי שניות, עם עצירה לבקשה ושמירה של מה שכבר נמשך.

תוצאות חדשות מתווספות לפי מספר הגרלה; תוצאה סותרת אינה דורסת תוצאה קיימת. הסימונים אינם נמחקים. במצב כשל מוצגת הודעה, והספר הקיים נשאר זמין. אין הבטחה לקבלת תוצאה ברגע פרסומה. אם אתר המקור משנה מבנה, מתבצעת עצירה ולא המצאת תוצאות.

## הפעלה ופיתוח

ללא התקנת תלויות:

```bash
python3 scripts/export.py
node scripts/embed.mjs
npm run dev
```

השרת המקומי מאזין לפורט 4173 כברירת מחדל או ל־PORT. יציאה לאתר המקור מחייבת גישת רשת תקינה. קובץ `web/chance-book.html` נפתח גם בלי אינטרנט; בו העדכון החי מושבת ויש אפשרות לייבוא CSV.

```bash
node --test tests/*.cjs tests/*.mjs
node scripts/embed.mjs
bash scripts/build.sh
node scripts/validate-artifact.mjs
```

`web/` מכיל את קוד הדפדפן. `worker/scraper.mjs` מפרש את המקור; `worker/handler.mjs` משרת את היישום ואת API התוצאות. `scripts/embed.mjs` מייצר מהם Worker ESM ללא תלויות. `dist/` הוא פלט בנייה ולא מקור לעריכה. זהות האתר והרשאותיו נשמרו.

## המאגר המצורף

3,250 תוצאות ייחודיות, הגרלות 50566–53838, מפברואר 2025 עד נובמבר 2026. חסרים 23 מספרי הגרלה בטווח. זהו צילום מצב חלקי ממקור עצמאי, ללא אימות רשמי. עדכונים חיים מתווספים לאחר פתיחת הספר. סדר cards תמיד: עלה, לב, יהלום, תלתן. לא הושלמו שעות חסרות באופן מלאכותי.

## שמירה וניתוח

הערות ב־localStorage ונתוני תוצאות ב־IndexedDB במכשיר ובדפדפן הנוכחיים. אין סנכרון מחברות בין מכשירים. גיבוי JSON מעביר את הנתונים והסימונים. צילום ה־HTML העצמאי הוא המאגר המצורף; להעברת עדכונים וסימונים יש להוריד גיבוי.

השכיחויות והצירופים מתייחסים לכל הטווח המסונן. רצפים ופערים נעצרים כאשר מספרי הגרלות אינם עוקבים. ציון Z תיאורי בלבד: (count-n/8)/sqrt(n*7/64). בחירה מותאמת וריבוי בדיקות משפיעים על הפרשנות. אין מודל לניבוי ואין המלצות לשליחת טפסים.

## אימות

12 בדיקות של המנוע והמגרד, כולל HTML אמיתי שנמשך מהמקור עם הגרלה 53839, שגיאות מקור ומיזוג ללא דריסת סתירות. תצוגת הספר והחלוניות נבדקה בדפדפן. לא בוצעה בדיקת מגע על Android פיזי.

## פריסה ל־Vercel

בייבוא המאגר `analist0/chance-fastapi`, בחרו בענף `digital-chance-book` וב־Root Directory: `digital-book`. Framework Preset: Other. קובץ vercel.json מגדיר buildCommand והפלט public. אין צורך במפתחות API או במשתני סביבה. תוצאות עדכניות נמשכות ב־Node.js דרך api/results.mjs.

הדפדוף משתמש בשתי שכבות עם transform ו־Web Animations API. אין פילטר brightness בזמן התנועה ואין fade אחרי החלפת דף. תוכן העמוד הבא מוכן לפני תחילת המעבר. הגרירה מעדכנת רק transform בתוך requestAnimationFrame; זמן ההשלמה מותאם למרחק ולמהירות. prefers-reduced-motion מכובד. קצב הרענון בפועל תלוי במכשיר ובדפדפן.
